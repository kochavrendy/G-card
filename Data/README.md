このディレクトリの `cards.json` をG-cardのカード登録の正本として扱います。

- 収録レコード: 973
- アプリ用メタデータ: 839レコード（通常・別イラスト・パラレル・トークンを含む）
- デッキ構築対象: 826レコード／388種
- トークン: 13レコード／5種（通常デッキ一覧からは除外）

`is_parallel` をパラレル判定の正とし、カード番号末尾の `+` だけでは判定しません。同じ論理カードでも名前・効果・レアリティ・画像が異なる場合があるため、バリアント単位の値を保持します。画像識別にはファイル名だけでなく `picture` のサブディレクトリを含むパスを使います。
